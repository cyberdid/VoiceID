# RawNet3

| | |
| :-- | :-- |
| Модель | [github.com/jungjee/RawNet](https://github.com/jungjee/RawNet) |
| Стаття | [arXiv:2203.08488](https://arxiv.org/pdf/2203.08488) |
| Ембединг | **256** |
| Тренувальні дані | VoxCeleb1 + VoxCeleb2 |
| Архітектура | ECAPA-TDNN + RawNet2 |
| Заявлений EER | **0,73–0,89%** |

## Особливість

**Приймає на вхід необроблений аудіосигнал** — виняток із загального пайплайну
(див. [[concepts/speaker-embedding]]): немає окремого кроку feature extraction,
модель сама вчить фільтри з waveform.

Наслідок для нас: **немає ризику неузгодженості feature extraction**, але й немає
можливості підкрутити фронтенд. Чутливість до амплітуди/каналу може бути іншою, ніж
у мел-спектрограмних моделей — це варто перевірити на телефонних даних окремо.

RawNet і RawNet2 — попередні версії, «менш досконалі, показували гірші результати».
Брати тільки **RawNet3**.

## Оцінка для проєкту

**Резервний кандидат.** Заявлений EER — у топ-3. На українських даних не тестувалась.
Цікавий саме як **архітектурно інша** система для [[concepts/score-normalization|score fusion]]
з мел-спектрограмною ([[models/resnet]]) — різні вхідні представлення дають шанс на
некорельовані помилки.
