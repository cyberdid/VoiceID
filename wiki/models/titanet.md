# TitaNet

| | |
| :-- | :-- |
| Модель | `nvidia/speakerverification_en_titanet_large` (NeMo) |
| Стаття | [arXiv:2110.04410](https://arxiv.org/pdf/2110.04410) |
| Ембединг | **192** |
| Тренувальні дані | VoxCeleb, **NIST SRE, Fisher**, LibriSpeech |
| Архітектура | ContextNet + channel attention pooling |
| Заявлений EER | **0,66%** — найнижчий серед усіх кандидатів |

## Особливість

Єдина модель у списку, у тренувальних даних якої є **NIST SRE і Fisher** — телефонні
корпуси. Якщо наш цільовий домен телефонний (8 кГц), це потенційно велика перевага
перед моделями, тренованими лише на VoxCeleb (YouTube-інтерв'ю).
Пор. з [[speakernet]], яку прямо застерігають щодо телефонних записів.

## Що ми знаємо з практики

- Часто використовувалась в експериментах на україномовних даних, показувала «непогані результати».
- В одному експерименті **обійшла [[pyannote]] і [[wavlm]] base/base+**.
- Прямого порівняння з [[resnet]] / [[ecapa-tdnn]] на українських даних у джерелах **немає**.

## Ризики

**Складне завантаження**: «виникають помилки при встановленні необхідних бібліотек» (NeMo —
важка залежність). Закласти час на встановлення або одразу передбачити Docker.

## Оцінка для проєкту

**Брати в шортліст**, але третьою — після [[resnet]] і [[ecapa-tdnn]], через вартість
встановлення. Якщо дані телефонні — підняти пріоритет.
