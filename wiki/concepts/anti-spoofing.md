# Anti-spoofing / детекція діпфейків

**Суміжна задача, не наша.** Сторінка існує, щоб не плутати її з ідентифікацією мовця
і щоб зафіксувати, що з неї можна взяти.

## Різниця

| | Ідентифікація мовця | Anti-spoofing |
| :-- | :-- | :-- |
| Питання | **хто** говорить | чи це взагалі **людина** |
| Вихід | ембединг → зіставлення з базою | одна ймовірність (bonafide vs spoof) |
| Модель | енкодер | бінарний класифікатор |
| Метрика | EER на trial'ах пар/watchlist | EER bonafide vs spoof |

Модель з [[sources/nb-voxceleb-real-audio-benchmark]] не вміє відповісти «хто це» —
вона відповідає «чи справжній». Це різні голови на (можливо) спільному фронтенді.

## Чому це все ж дотично

**1. Спільний фронтенд.** Обидві задачі знімають ознаки з SSL-моделі
([[models/wav2vec2]], [[models/wavlm]]). Рецепти дотреновування переносяться —
[[concepts/fine-tuning]].

**2. Спільна вразливість.** Голосова біометрія без anti-spoofing атакується
синтезованим голосом: TTS-клон обійде верифікацію, бо ембединг буде схожий.
Якщо система проєкту матиме безпековий контекст (доступ, шахрайство), **anti-spoofing
стає обов'язковим другим щитом**, а не опцією. *(висновок агента)*

**3. Джерело практик.** З ноутбука взято: telephony filter
([[concepts/audio-preprocessing]]), схему розморожування ([[concepts/fine-tuning]]),
реалізацію `compute_eer` і повний набір методологічних пасток
([[concepts/eer-and-metrics]]).

## Що знати про ноутбук

Лінійка чекпойнтів: `v1_final` → V5 Ultimate (поріг 0,4185) / fresh baseline (поріг 0,5)
→ **V6 Gold** (EER 10,00%, поріг 0,2725) → **V7 Elite** (EER 1,67%, поріг 0,2611).
Дані: ElevenLabs (spoof) vs In-The-Wild + VoxCeleb1 (bonafide).
Повні числа, баги та застереження — на сторінці джерела.
