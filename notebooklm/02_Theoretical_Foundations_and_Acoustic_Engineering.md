# Теоретичні основи та акустична інженерія (Theoretical Foundations & Acoustic Engineering)

## 1. Акустичні параметри голосу та фізіологічні кореляти

Ідентифікація диктора базується на вилученні біометричних характеристик голосу, зумовлених як анатомічною будовою голосового тракту (гортань, глотка, ротова й носова порожнини), так і набутими артикуляційними звичками мовця.

### 1.1. Базові акустичні дескриптори
1. **Фундаментальна частота (F0 / Pitch):**
   - Частота коливань голосових зв'язок під час фонації (зазвичай 85–180 Гц для чоловіків, 165–255 Гц для жінок).
   - Інформативним є не абсолютне значення (воно коливається від інтонації та стресу), а статистичний розподіл: середнє, медіана, дисперсія та контур просодії.
2. **Форманти (F1, F2, F3, F4):**
   - Резонансні частоти голосового тракту.
   - **F1 і F2** корелюють з артикуляцією голосних (підйом і ряд язика).
   - **F3, F4 і вище** корелюють з індивідуальною геометрією голосового тракту мовця (довжина тракту, об'єм ротоглотки) і є високоінформативними маркерами ідентичності.
3. **Мікроакустичні флуктуації (Perturbation Measures):**
   - **Jitter (джитер):** Короткочасна нестабільність періоду основного тону між сусідніми циклами коливань зв'язок. Характеризує мікротремор гортанних м'язів.
   - **Shimmer (шимер):** Короткочасна нестабільність амплітуди між сусідніми періодами.
   - **HNR (Harmonics-to-Noise Ratio):** Співвідношення гармонійної енергії мовлення до турбулентного шуму неповного змикання зв'язок (вимірюється в дБ). Високий HNR свідчить про дзвінкий голос; низький — про придиховий або хрипкий тембр.

### 1.2. Спектральні репрезентації для нейромереж
- **MFCC (Mel-Frequency Cepstral Coefficients):** Класичний дескриптор, що використовує шкалу мелів для симуляції нелінійного людського слуху та дискретне косинусне перетворення (DCT) для декорреляції ознак.
- **Log-Mel Filterbanks (Fbank):** Сучасний стандарт глибокого навчання (80 або 64 фільтри, вікно 25 мс, крок 10 мс). Зберігає просторово-часову кореляцію спектрограми, на якій згорткові шари (ResNet, TDNN) ефективно вчаться виділяти як формантні переходи, так і тембральні гармоніки.

## 2. Функції втрат для метричного навчання (Loss Functions)

Звичайний Softmax Loss (Cross-Entropy) навчає мережу розділяти класи гіперплощинами в евклідовому просторі, але не забезпечує достатньої компактності класів (intra-class compactness) та максимальної кутової розбіжності між різними класами (inter-class discrepancy). У верифікації дикторів нові обличчя/голоси з'являються під час інференсу, тому потрібне **кутове метричне навчання на гіперсфері**.

### 2.1. Еволюція Angular Margin Softmax
Вектори ембедингу $x$ та ваги класів $W$ нормалізуються на одиничну гіперсферу: $\|x\| = 1$, $\|W_i\| = 1$. Скалярний добуток перетворюється на косинус кута: $W_i^T x = \cos \theta_i$.

1. **A-Softmax (SphereFace):**
   $$L = -\log \frac{e^{s \cos(m \theta_{y})}}{e^{s \cos(m \theta_{y})} + \sum_{j \neq y} e^{s \cos \theta_j}}$$
   Мультиплікативний марджин $m$. Складний в оптимізації, вимагає анілінгу.

2. **AM-Softmax (CosFace):**
   $$L = -\log \frac{e^{s (\cos \theta_{y} - m)}}{e^{s (\cos \theta_{y} - m)} + \sum_{j \neq y} e^{s \cos \theta_j}}$$
   Адитивний косинусний марджин $m \in [0.2, 0.4]$, де $s$ — радіус гіперсфери (зазвичай $s = 30$ або $32$).

3. **AAM-Softmax (ArcFace) — Галузевий стандарт:**
   $$L = -\log \frac{e^{s \cos(\theta_{y} + m)}}{e^{s \cos(\theta_{y} + m)} + \sum_{j \neq y} e^{s \cos \theta_j}}$$
   Адитивний кутовий марджин $m \in [0.2, 0.5]$. Накладає прямий штраф у просторі геодезичних відстаней на одиничній гіперсфері.

### 2.2. Стратегія Large Margin Fine-Tuning (LM-FT)
Стандартний рецепт SOTA систем (WeSpeaker, VoxWatch):
1. **Фаза 1 (Pre-training):** Навчання на коротких чанках аудіо (200 кадрів ~ 2,0 с) з помірним кутовим марджином ($m = 0,2$, $s = 32$). Використовується аугментація шумами (MUSAN) та модифікація швидкості (Speed Perturbation 0.9, 1.0, 1.1).
2. **Фаза 2 (Large Margin Fine-Tuning):**
   - Збільшення довжини чанків до **6,0 секунд** (600 кадрів) або повних висловлювань.
   - Збільшення марджину $m$ до **0,5**.
   - **Вимкнення Speed Perturbation** (щоб не розмивати тонкі тембральні відмінності на фінальній стадії).
   - Зниження Learning Rate на 1–2 порядки.
   Цей крок забезпечує суттєве зниження EER (наприклад, з 1,31% до 0,72% для ResNet34).

### 2.3. Sub-center ArcFace
Для роботи з шумними інтернет-корпусами (де під однією міткою можуть бути записи різної якості або помилкові переплутування): кожному класу виділяється $K$ суб-центрів ($K=3$), і зразок притягується до найближчого підцентру. Це запобігає колапсу моделі через викиди.

## 3. Пайплайн акустичного препроцесингу

```
Raw Audio (.ogg / .wav / .mp3)
       │
       ▼
1. Декодування FFmpeg ──► Перетворення в 16 000 Гц, 16-bit PCM, Mono
       │
       ▼
2. Voice Activity Detection (VAD) ──► Видалення тиші, пауз, немовного шуму (Silero VAD)
       │
       ▼
3. Контроль якості та тривалості ──► Відсікання записів < 3,0 с чистого мовлення
       │
       ▼
4. (Опціонально) Telephony Filter ──► Симуляція 8 кГц телефонного каналу при потребі
       │
       ▼
5. Розрахунок ознак ──► 80-dim Log-Mel Filterbanks (Fbank), CMN
```

### 3.1. Voice Activity Detection (VAD)
- **Чому це критично:** Робота з немовними відрізками катастрофічно знижує роздільну здатність ембедингів. У літературі зафіксовано, що неякісний VAD коштує **до ~3 відсоткових пунктів деградації Diarization Error Rate (DER)**.
- **Інструмент:** **Silero VAD** — легка, швидка рекурентна нейромережа, що працює на чанках 30 мс, стійка до побутових шумів та музики.

### 3.2. Telephony Filter (Симуляція вузькосмугового каналу)
При переході на телефонні перехоплення виникає ефект «зрізання» смуги пропускання до 300–3400 Гц.
Для симуляції такого каналу використовується блок:
```python
import torch.nn as nn
import torchaudio.transforms as T

telephony_filter = nn.Sequential(
    T.Resample(orig_freq=16000, new_freq=8000),
    T.Resample(orig_freq=8000, new_freq=16000)
)
```
Цей фільтр необоротно обрізає частотний діапазон вище 4 кГц, змушуючи нейромережу під час донавчання спиратися виключно на нижні форманти F1–F3 і не покладатися на високочастотні гармоніки студійної якості.

## 4. Співвідношення: Speaker Recognition vs. Voice Anti-Spoofing

| Параметр | Speaker Identification (Мовець) | Voice Anti-Spoofing (Справжність) |
| :--- | :--- | :--- |
| **Цільове питання** | «Хто саме говорить?» ($N$-класова / метрична задача) | «Чи це жива людина чи генерація?» (Бінарна класифікація) |
| **Тип моделі** | Енкодер ембедингів (ResNet, ERes2Net, TDNN) | Бінарний класифікатор (Linear head поверх Wav2Vec2/RawNet) |
| **Простір ознак** | Гіперсфера $\mathbb{S}^{D-1}$ з косинусною відстанню | Ймовірність $p \in [0, 1]$ (Sigmoid/BCE) |
| **Цільовий сигнал** | Тембр голосового тракту, індивідуальні форманти | Спектральні артефакти вокодерів, фазові спотворення |
| **Роль у пайплайні VoiceID** | Основне ядро системи | Попередній аудит та фільтр штучних вкидів |
